# Docs staleness audit, slice 6e: the remaining `man/` pages (2026-10-01, S842)

Read-only audit. Nothing in the repo was changed except this report and the session records.

## Audit summary

- **Scope:** the last 126 of the 267 `man/*.Rd` pages: slices 6a-6d took 141 (the first column of each slice's "Items audited"
  table), so 126 remain, and this slice covers all of them. `man/` is generated from roxygen in `R/`, so a fix goes in the
  `R/*.R` roxygen block (datasets in their documentation file), then `devtools::document()`. Eight themed sets (ids RE-RL,
  continuing after slice 6d's RA-RD): RE obfuscation and ancestry/cross-center (16 pages), RF kinship overrides and snapshots
  (14), RG pedigree-tree building (12), RH pedigree getters (13), RI configuration and species (18), RJ groups, potential
  parents and pyramid (18), RK pedigree-check datasets and examples (16), RL utilities, S3 methods and package page (19).
- **Criterion:** does each checkable claim (argument list and defaults, return value and fields, described behavior, column
  names, example runnability, `\link`/`@seealso` targets, counts) match today's code? Read from the implementation and by
  running the calls, not from the roxygen alone.
- **Method:** eight read-only subagents, one per set. This session then re-ran or re-read the code for the moderate
  findings listed under "Verified by me" below. Minor findings are the agent's own check: **R** = re-read the code, **A** =
  ran it. Code candidates (ids CE-CL) are the agents' observations only; none was re-checked here.
- **Coverage:** 126 of 126 pages. Every page of the 126 appears once in "Items audited".
- **Findings:** 0 critical, **26 moderate, 69 minor** (95), plus **46 code candidates**.
  The moderates are mostly returns and defaults the page states wrongly: `getAnimalsWithHighKinship` documents defaults it
  does not have (RF3), the two Excel readers accept files their own validators then reject (RF1, RF2), `trimPedigree` does
  less by default than its `@return` says (RG1), and several helpers silently return something other than the described
  shape (RJ1, RJ2, RJ6, RL6).
