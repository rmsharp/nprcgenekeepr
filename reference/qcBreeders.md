# Potential breeder IDs (29 baboons)

A character vector of 29 baboon IDs that are potential breeders.

## Usage

``` r
data(qcBreeders)
```

## Format

An object of class `character` of length 29.

## Source

qcBreeders is a character vector of 3 males and 26 females from the
`qcPed` data set.

These 29 animal IDs are used for examples and unit tests. They were
initially selected for having low kinship coefficients.
